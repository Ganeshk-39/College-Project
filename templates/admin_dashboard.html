Welcome, Administrator

Use the menu or quick buttons below to manage the OCD Detection System.

Upload Dataset: Used to upload the OCD patient dataset in CSV format for further processing.

Preprocess: Performs data cleaning, encoding of categorical values, normalization, and splitting into training and testing sets.

Train Models: Trains multiple Machine Learning and Deep Learning algorithms to classify OCD subtypes.

Comparison: Displays performance comparison of all trained models using accuracy, precision, recall, F1-score, and graphs.

Manage Users: Allows the administrator to view and manage all registered user accounts.

Logout: Securely logs out the administrator from the system.
