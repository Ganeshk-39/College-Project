Welcome to the OCD Detection System

The Obsessive–Compulsive Disorder (OCD) Detection System is designed to assist users in identifying potential OCD patterns using advanced machine learning and deep learning techniques. This system analyzes user-provided inputs and clinical data to provide accurate and reliable predictions.

As a registered user, you can perform OCD type prediction, explore analytical insights derived from the dataset, and manage your personal profile securely. The system ensures data confidentiality while delivering fast and interpretable results to support early awareness and decision-making.

Please use the navigation options available in the top menu or sidebar to access different features of the system. This platform is intended for educational and research purposes and does not replace professional medical diagnosis.
