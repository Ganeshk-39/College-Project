# A Machine Learning-Based Predictive Analytics Framework for Early Diagnosis of Obsessive-Compulsive Disorder (OCD)

A predictive analytics web application developed using Flask, Scikit-Learn, and Deep Learning to assist in the early diagnosis and classification of Obsessive-Compulsive Disorder (OCD).

---

## 📌 Features

- **User Authentication**: Secure Login and Registration system.
- **Admin Module**: Admin dashboard for dataset upload, inspection, and model training.
- **Machine Learning Models**:
  - Decision Tree Classifier
  - Random Forest Classifier
  - K-Nearest Neighbors (KNN)
  - Support Vector Machine (SVM)
  - Convolutional Neural Network (CNN)
- **Model Evaluation & Visualization**: Comparative metrics and performance plots.
- **Prediction Interface**: Predict OCD diagnosis based on patient clinical parameters.

---

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **Machine Learning / Deep Learning**: Scikit-Learn, TensorFlow / Keras, NumPy, Pandas
- **Data Visualization**: Matplotlib
- **Frontend**: HTML5, CSS3, Jinja2 templates

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone <YOUR_REPOSITORY_URL>
cd <REPOSITORY_FOLDER>
```

### 2. Create and Activate Virtual Environment
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
python app.py
```
Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your web browser.
